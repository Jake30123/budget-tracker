Set up Google Sheets sync

Budget Tracker stores your receipts in your own Google Sheet. Follow these steps once:

  1. Create a new Google Sheet.
  2. In that sheet, open Extensions → Apps Script.
  3. Replace the default code with the script from Code.gs in the repo, then click the save (disk) icon.
  4. Click Deploy → New deployment. Choose type Web app. Set "Execute as: Me" and "Who has access: Anyone". Click Deploy and authorize when prompted.
  5. Copy the Web app URL (it ends in /exec) and paste it below.
